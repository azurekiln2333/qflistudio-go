## Intentional technical corrections (documented)

The numeric/identifier multiset check compares against the old prose. Old prose
that is factually wrong is not binding, so these corrections intentionally change
content rather than preserve it:

1. **T161** — one basis point is one ten-thousandth. The old `百分之一基点` was
   wrong by two orders of magnitude. Corrected to `一个基点为万分之一`; this
   matches `(amount*basisPoints+5000)/10000`.
2. **T170** — MiB is `1 << 20`, i.e. 1024². The old `一百零二十四平方字节`
   described 1024² as "one hundred and twenty-four squared". Corrected to
   `1024×1024 字节`. This is the only place where the numeric multiset differs
   from the old prose: the checked delta is `1024 ×2` added, nothing removed
   (the old form used Chinese numerals, so it held no digit tokens).
3. **T187** — the savings factor is the number of files inside the current group
   minus one, not the number of groups minus one. Corrected to `组内文件数-1`;
   the literal `1` is unchanged.

No other numeric or identifier token changed anywhere in T161–T200.

综合离线应用

## tutorial.objective

能按交易 ID 对比两份账本，输出缺失、重复与金额不一致记录。

## tutorial.pitfalls.0

把重复 ID 直接覆盖会丢失重复交易证据。

## tutorial.pitfalls.1

两份账本总额相同也可能有不同的缺失或错账，不能只比较总和。

## tutorial.exercises.0.prompt

对同一 ID 的重复金额不一致单独报告冲突。

## tutorial.exercises.0.hint

先保持现有输入的结果，再为新边界增加独立输入。

## tutorial.exercises.0.answer

加载函数除重复集合外记录第一次金额与冲突标记，避免覆盖原始值，再按稳定 ID 顺序展示。

## tutorial.explain

本例从两段内存 CSV 文本加载账本，按交易 ID 对应逐笔记录，不涉及文件读写。加载时先保留第一笔并记录重复 ID，比较时取两边键集合的并集，按 ID 排序报告金额不符、重复和缺失。金额统一用整数分，避免浮点格式差异掩盖实际金额问题。示例刻意让重复记录金额相同，证明仅看汇总仍会漏掉结构错误。
